# Промакадемия — MVP платформы онлайн-профориентации

Веб-платформа профориентации, где школьник, студент или будущий соискатель проходит адаптивный визуальный тест, получает «профессии на заводе», проходит производственный симулятор предприятия и формирует цифровое портфолио.

Проект сделан по ТЗ с двухуровневой логикой:

```text
24 визуальных вопроса → динамический маппинг ролей → предприятие → квест → портфолио + сертификат + HR-скоринг
```

## Что реализовано

- Стартовый экран «Промакадемии».
- Адаптивный онлайн-тест из 24 визуальных вопросов.
- 6 профессиональных типов, по 4 вопроса на каждый тип.
- Динамический маппинг ролей на сервере.
- Автоматическое назначение одной основной и до двух вспомогательных профессий на заводе.
- Подбор и ранжирование предприятий по ролям, тегам и весам.
- Карточки предприятий с профессиями и пояснением рекомендации.
- Игровые сценарии предприятий с заданиями, ответами, баллами и обратной связью.
- Бейджи и прогресс-треки по итогам квеста.
- Цифровое портфолио пользователя.
- Сертификат прохождения производственного симулятора.
- HR-профиль компетенций с итоговыми баллами и скорингом готовности к практике.
- HR-дашборд предприятия.
- Демо-отправка цифрового портфолио на email.
- SQLite-база с seed-данными при первом запуске.
- Docker-сборка и запуск одной командой.

## Быстрый запуск через Docker

Скопируйте файл окружения:

```bash
cp server/.env.example server/.env
```

Соберите и запустите контейнер:

```bash
docker compose build
docker compose up -d
```

Откройте сайт:

[http://localhost:3000](http://localhost:3000)

Посмотреть статус:

```bash
docker compose ps
```

Посмотреть логи:

```bash
docker compose logs -f
```

Остановить:

```bash
docker compose down
```

При первом запуске `entrypoint.sh` автоматически:

1. создает SQLite-базу;
2. применяет `server/src/db/schema.sql`;
3. загружает демо-данные из `server/src/db/seed.js`;
4. запускает Express-сервер.

## Запуск без Docker

Нужен Node.js 20+ и npm.

```bash
cp server/.env.example server/.env
npm install
npm run init-db
npm run seed
npm start
```

Для разработки React-клиента:

```bash
cd client
npm install
npm run dev
```

## API

| Метод | URL | Назначение |
|---|---|---|
| `GET` | `/api/health` | Проверка работы сервера |
| `GET` | `/api/bootstrap` | Загрузка теста, предприятий, профессий и сценариев |
| `POST` | `/api/results/preview` | Расчет предварительного профиля и подбор предприятий |
| `POST` | `/api/results/final` | Сохранение финального результата |
| `POST` | `/api/email-results` | Демо-отправка результата на email |
| `GET` | `/api/hr/dashboard` | HR-дашборд предприятия, Basic Auth |
| `GET` | `/api/admin/summary` | Админ-сводка, Basic Auth |

## Демо-данные

В seed-данных есть:

- входной тест из 24 визуальных вопросов;
- 6 профилей результата:
  - `Инженер-производственник`;
  - `Технолог-контролер`;
  - `Логист-координатор`;
  - `Маркетолог-дизайнер`;
  - `Оператор автоматизированных систем`;
  - `Наставник по безопасности и HR`;
- предприятия:
  - `Промакадемия: учебный завод`;
  - `Т Плюс`;
- профессии предприятий;
- игровые сценарии и задания.

## Критерии приемки MVP

- Пользователь сначала проходит 24 визуальных вопроса.
- Система назначает одну основную и до двух вспомогательных профессий на заводе.
- Результат теста влияет на подбор предприятий и симуляторов.
- В карточке предприятия есть собственные профессии, квестовые задания и бейджи.
- После квеста формируется цифровое портфолио и сертификат.
- HR-дашборд получает профиль компетенций, итоговые баллы и скоринг готовности к практике.

## Авторизация администратора

Для `/api/admin/summary` используется Basic Auth.

По умолчанию:

```text
login: admin
password: secure-pass
```

Значения меняются в `server/.env`.
