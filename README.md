# ПрофМаршрут — MVP платформы онлайн-профориентации

Веб-платформа профориентации, где пользователь сначала проходит обязательный входной тест, получает предварительный профиль интересов, затем выбирает рекомендованное предприятие и проходит игровой сценарий внутри карточки компании.

Проект сделан по ТЗ с двухуровневой логикой:

```text
входной тест → профиль интересов → подбор предприятий → карточка предприятия → игровой сценарий → финальный результат
```

## Что реализовано

- Стартовый экран с описанием платформы и запуском теста.
- Общеплатформенный входной профориентационный тест.
- Расчет предварительного профиля пользователя на сервере.
- Подбор и ранжирование предприятий по тегам и весам.
- Карточки предприятий с профессиями и пояснением рекомендации.
- Игровые сценарии предприятий с заданиями, ответами, баллами и обратной связью.
- Финальный результат: общий профиль + результат сценария предприятия.
- Демо-отправка результата на email.
- Административная структура: общий тест отдельно от контента предприятий.
- SQLite-база с seed-данными при первом запуске.
- Docker-сборка и запуск одной командой.

## Быстрый запуск через Docker

Скопируйте файл окружения:

```bash
cp server/.env.example server/.env
```

Соберите и запустите контейнер:

```bash
docker compose build
docker compose up -d
```

Откройте сайт:

[http://localhost:3000](http://localhost:3000)

Посмотреть статус:

```bash
docker compose ps
```

Посмотреть логи:

```bash
docker compose logs -f
```

Остановить:

```bash
docker compose down
```

При первом запуске `entrypoint.sh` автоматически:

1. создает SQLite-базу;
2. применяет `server/src/db/schema.sql`;
3. загружает демо-данные из `server/src/db/seed.js`;
4. запускает Express-сервер.

## Запуск без Docker

Нужен Node.js 20+ и npm.

```bash
cp server/.env.example server/.env
npm install
npm run init-db
npm run seed
npm start
```

Для разработки React-клиента:

```bash
cd client
npm install
npm run dev
```

## API

| Метод | URL | Назначение |
|---|---|---|
| `GET` | `/api/health` | Проверка работы сервера |
| `GET` | `/api/bootstrap` | Загрузка теста, предприятий, профессий и сценариев |
| `POST` | `/api/results/preview` | Расчет предварительного профиля и подбор предприятий |
| `POST` | `/api/results/final` | Сохранение финального результата |
| `POST` | `/api/email-results` | Демо-отправка результата на email |
| `GET` | `/api/admin/summary` | Админ-сводка, Basic Auth |

## Демо-данные

В seed-данных есть:

- входной тест из 7 вопросов;
- профили результата;
- предприятия:
  - `Т Плюс`;
  - `Вятка-Мебель`;
  - `ЭкоЛаб Регион`;
- профессии предприятий;
- игровые сценарии и задания.

## Критерии приемки MVP

- Пользователь сначала проходит входной тест, а не попадает сразу в предприятие.
- Тест рассчитывает предварительный профиль.
- Результат теста влияет на подбор предприятий.
- В карточке предприятия есть собственные профессии и игровые задания.
- Сценарий предприятия запускается после завершения входного теста.
- Финальный результат объединяет тест и сценарий выбранного предприятия.

## Авторизация администратора

Для `/api/admin/summary` используется Basic Auth.

По умолчанию:

```text
login: admin
password: secure-pass
```

Значения меняются в `server/.env`.
