# Промакадемия

«Промакадемия» — платформа профориентации для школьников, студентов и будущих соискателей, которая переводит интерес пользователя в понятную «профессию на заводе», а затем проверяет эту роль в производственном симуляторе.

Главная логика проекта:

```text
24 визуальных вопроса
→ динамический маппинг профессиональных типов
→ 1 основная и до 2 вспомогательных профессий на заводе
→ предприятие и производственный квест
→ баллы, бейджи и прогресс готовности
→ цифровое портфолио и сертификат
→ HR-дашборд предприятия
```

Платформа не начинается с выбора предприятия. Сначала пользователь проходит визуальный тест, система определяет профессиональную роль, и только после этого открывает подходящие предприятия и квестовые задания.

## Заявленная логика

Пользователь заходит на платформу и проходит адаптивный онлайн-тест из 24 визуальных вопросов: по 4 вопроса на каждый из 6 профессиональных типов.

Система мгновенно обрабатывает ответы и присваивает:

- одну основную профессию на заводе;
- до двух вспомогательных профессий;
- профиль компетенций;
- рекомендации по предприятиям и симуляторам.

Поддерживаемые профессиональные типы:

- Инженер-производственник;
- Технолог-контролер;
- Логист-координатор;
- Маркетолог-дизайнер;
- Оператор автоматизированных систем;
- Наставник по безопасности и HR.

После теста пользователь проходит производственный симулятор предприятия. Квест начисляет баллы, бейджи и прогресс готовности к практике. В финале формируются цифровое портфолио и сертификат, а HR-дашборд предприятия получает профиль компетенций с итоговыми баллами и скорингом.

## Пайплайн реализации

Проект выстроен в порядке, который отражает бизнес-логику, а не презентацию фронтенда.

1. Схема данных.
2. Маршруты бэкенда.
3. Seed-данные.
4. Автотесты админки и HR-дашборда.
5. Фронтенд.

## 1. Схема данных

Файл: `server/src/db/schema.sql`

Ключевые сущности:

- `global_orientation_tests` — общий визуальный тест платформы;
- `global_test_questions` — 24 вопроса теста;
- `global_test_answers` — варианты ответов, баллы и role-tags;
- `global_result_profiles` — профессиональные типы и интерпретации;
- `enterprises` — предприятия и их role-tags;
- `enterprise_professions` — профессии предприятия;
- `enterprise_game_scenarios` — производственные симуляторы;
- `enterprise_game_questions` — квестовые задания;
- `enterprise_game_answers` — ответы, баллы, предпочтительный вариант;
- `enterprise_game_tasks` — payload интерактивной механики;
- `user_sessions` — пользовательские сессии;
- `user_results` — итог теста, квеста, портфолио, сертификата и HR-профиля.

SQLite используется без ORM. Доступ к БД сделан через async-wrapper:

- `dbRun`;
- `dbGet`;
- `dbAll`.

Файл: `server/src/db/db.js`

## 2. Маршруты бэкенда

Файл: `server/src/routes/api.js`

Основная логика находится на сервере:

- расчет role-score по ответам;
- выбор основной и вспомогательных профессий;
- ранжирование предприятий;
- расчет результата квеста;
- формирование портфолио;
- генерация сертификата;
- подготовка HR-профиля и скоринга готовности к практике.

API:

| Метод | URL | Назначение |
|---|---|---|
| `GET` | `/api/health` | Проверка сервера |
| `GET` | `/api/bootstrap` | Тест, роли, предприятия, профессии и сценарии |
| `POST` | `/api/results/preview` | Расчет профессий и подбор предприятий после теста |
| `POST` | `/api/results/final` | Сохранение результата квеста, портфолио, сертификата и HR-профиля |
| `POST` | `/api/email-results` | Демо-отправка цифрового портфолио |
| `GET` | `/api/admin/summary` | Админ-сводка, Basic Auth |
| `GET` | `/api/hr/dashboard` | HR-дашборд предприятия, Basic Auth |

Админские маршруты защищены Basic Auth.

По умолчанию:

```text
login: admin
password: secure-pass
```

Значения задаются в `server/.env`.

## 3. Seed-данные

Файл: `server/src/db/seed.js`

Seed создает тестовые данные, необходимые для полноценной демонстрации логики:

- 24 визуальных вопроса;
- 6 профессиональных типов;
- предприятие «Промакадемия: учебный завод»;
- предприятие «Т Плюс»;
- профессии предприятий;
- производственные квесты;
- ответы, баллы, бейджи и progress-track payload.

При развертывании seed заносится в БД автоматически.

Файл: `entrypoint.sh`

```sh
node src/db/init-db.js
node src/db/seed.js
node src/index.js
```

Это означает, что после `docker compose up -d` база уже содержит тест, роли, предприятия и квесты.

## 4. Автотесты админки

Файл: `server/tests/admin-api.test.js`

Тест проверяет полный серверный контур:

- инициализацию тестовой SQLite-БД;
- загрузку seed-данных;
- наличие 24 вопросов;
- наличие 6 ролей;
- отказ админки без Basic Auth;
- успешный `/api/admin/summary` с Basic Auth;
- расчет preview-результата;
- сохранение final-результата;
- появление записи в `/api/hr/dashboard`;
- наличие сертификата, бейджей и readiness-score.

Запуск:

```bash
cd server
npm run test:admin
```

## 5. Фронтенд

Фронтенд показывает заявленную пользовательскую логику:

- старт «Промакадемии»;
- прохождение 24 визуальных вопросов;
- экран профессий на заводе;
- выбор предприятия;
- производственный симулятор;
- портфолио;
- сертификат;
- HR-скоринг.

Рабочая Docker-статика:

- `client/dist/index.html`;
- `client/dist/styles.css`;
- `client/dist/app.js`.

React/Vite/Tailwind-исходники оставлены в `client/src` как основа для дальнейшего развития клиентского приложения.

## Быстрый запуск

```bash
cp server/.env.example server/.env
docker compose build
docker compose up -d
```

Сайт:

[http://localhost:3000](http://localhost:3000)

Проверка:

```bash
docker compose logs -f
docker compose ps
```

Остановка:

```bash
docker compose down
```

## Запуск без Docker

Нужен Node.js 20+ и npm.

```bash
cp server/.env.example server/.env
npm install
npm run init-db
npm run seed
npm start
```

## Технологии

Технологии обслуживают заявленную логику проекта:

- Node.js 20+;
- Express 4.21;
- SQLite 3 через `sqlite3`;
- Docker и docker-compose;
- React 18 / Vite 5 / Tailwind CSS 3.4 для дальнейшего развития клиентского приложения.

Важно: `better-sqlite3` не используется.

## Критерии готовности

- После развертывания в БД автоматически есть 24 визуальных вопроса.
- Тест назначает основную и вспомогательные профессии.
- Предприятия ранжируются по role-tags.
- Производственный симулятор начисляет баллы и бейджи.
- Финал содержит цифровое портфолио и сертификат.
- HR-дашборд получает профиль компетенций и readiness-score.
- Админские маршруты закрыты Basic Auth.
- Автотест админки проходит.
